# GSD Bot - Быстрый старт

## Что уже готово (MVP base):

### ✅ Инфраструктура
- Docker-compose с PostgreSQL + Redis
- FastAPI backend с async SQLAlchemy
- Aiogram 3 бот с FSM
- Модели БД для всех сущностей
- REST API endpoints

### ✅ Функционал бота
- Регистрация при /start
- Запись приёма пищи (2 шага: кнопка → текст)
- Автотаймер на 1 час после еды
- Замер глюкозы с определением типа (натощак/после еды)
- Автоопределение нормы (≤5.1 натощак, ≤7.0 после еды)
- Запись инсулина с типом (короткий/длинный)
- Главное меню с 4 кнопками

## Что делать дальше:

1. **Получить токен бота:**
   - Написать [@BotFather](https://t.me/BotFather)
   - Команда `/newbot`
   - Скопировать токен

2. **Настроить .env:**
```bash
cd "/Users/andreykhomenkov/Desktop/Проект Ани/gsd-bot"
cp .env.example .env
nano .env  # вставить BOT_TOKEN и SECRET_KEY
```

3. **Запустить:**
```bash
docker-compose up -d
docker-compose logs -f app
```

4. **Протестировать бота в Telegram**
